## Реализация — 15.10.2026

Поручение владельца: локально выполнить T08 без commit/push/deploy.

- POST /lessons атомарно создаёт Lesson + LessonStudent; один действующий участник
  выбирается автоматически, несколько требуют student_user_id. Ноль, чужой/неподходящий
  ID, отключённый аккаунт, закончившееся зачисление/связь или отозванная история
  дают 422 без частичной записи. Pending, но включённый аккаунт допустим для записи
  заранее. Course row lock, затем locks StudentCourse/TeacherStudent/User, одна
  транзакция, rollback в том числе после вставки пары и при ошибке формирования ответа.
- Duration default 55, положительный integer, NOT NULL/check в PostgreSQL.
  Create/update требуют aware datetime и нормализуют в UTC; фильтры списка тоже
  требуют timezone. Переполнение UTC/end datetime отклоняется без записи.
- scheduled/completed/cancelled, ручные переходы через PATCH; перенос отдельного урока.
  Отмена сохраняет участника, ДЗ, материалы/ответы; сама по себе не делает историю
  read-only. Архив остаётся отдельным состоянием со всеми запретами D02.
  Restore архива сохраняет status. Student/admin не получают teacher workflow.
- GET /lessons?status=... фильтрует до count/pagination с прежними SQL scopes.
  Course.call_url, Lesson.call_url_override, effective_call_url реализованы по D03;
  null очищает ссылку/замену. HTTP(S) проверяется общей Pydantic валидацией,
  backend внешний адрес не скачивает. Fallback динамический и для старых уроков.
- Create/update возвращают предупреждение teacher_time_overlap с IDs собственных
  конфликтующих уроков, сохраняя операцию. Полуоткрытые интервалы: смежные не
  конфликтуют. Текущий урок, cancelled, архивные уроки/курсы исключаются; completed
  учитывается. Detail/student list не содержат чужие conflict IDs (warnings=[]).
  Предупреждение не является системой бронирования. Отдельные пороги дат не
  вводились: в требованиях нет согласованных значений.
- Миграция 29e67248e0f3 создана Alembic autogenerate на guarded lgg-test, дополнена
  enum lifecycle, check constraint, backfill и pre-DDL guards. Старые NULL duration
  становятся 55, положительные значения/история сохраняются, старый status scheduled.
  Legacy duration≤0 останавливает upgrade без частичного DDL. Downgrade отказывается
  терять non-scheduled status и meeting links; backfilled 55 остаётся числом при
  допустимом downgrade, бывший NULL не угадывается.
