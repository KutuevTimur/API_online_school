## Согласованный контракт · 16.10.2026

D11 принят владельцем 16.10.2026 ответом «все согласую» на полный предложенный
пакет правил. Это согласование требований, не разрешение реализации.

- Регулярная запись создаёт встречи на выбранные 1–12 недель, по умолчанию 4,
  включая первую выбранную дату; только будущие встречи. Продление ручное,
  фонового scheduler/автопродления нет. Праздники автоматически не пропускаются.
- Одна серия: один ученик, один курс, один день недели и время Europe/Moscow;
  длительность по умолчанию 55 минут, изменяема перед подтверждением. Разные дни
  недели — отдельные серии. Встречи сразу появляются в расписании.
- Предпросмотр показывает ученика, курс, все даты/время/длительность, количество
  новых встреч и последнюю дату; создание только явным подтверждением. Конфликты
  отмечены по датам и требуют явного подтверждения после предупреждения D03;
  смежные интервалы не конфликтуют, сохранение при пересечении разрешено.
- Перенос с подтверждением «было → станет» и отмена затрагивают одну встречу.
  Стабильная идентичность исходного вхождения сохраняет исключение: продление
  не воссоздаёт отменённую/перенесённую встречу на исходное время. Остальные даты,
  материалы, ответы и история сохраняются.
- Продление добавляет следующие недели после прежней исходной границы серии,
  независимо от переносов; новый preview/подтверждение и количество добавляемых
  встреч обязательны. Повтор запроса, две вкладки и конкурентное продление
  не создают дублей. Ручные встречи автоматически к серии не присоединяются.
- Остановка серии запрещает дальнейшее продление, сохраняя назначенные встречи.
  Отдельная массовая отмена перечисляет даты и требует подтверждения; затрагивает
  только будущие scheduled этой серии, включая перенесённые. Проведённые встречи
  и материалы сохраняются. Массовая смена времени серии отложена: новый постоянный
  слот — новая серия; отдельный урок переносится обычным способом.
- Пакет атомарен: при ошибке/утрате прав/архиве курса/недопустимой дате ничего
  не сохраняется, показываются причина и обновлённый preview. После timeout сначала
  восстановить результат операции чтением, затем безопасно повторять. Новые
  пересечения требуют обновлённого предупреждения и явного подтверждения.
  Дедлайны пересчитываются по D04 в той же транзакции, checked не меняются.
- Норма необязательна, положительное целое, принадлежит паре teacher–student;
  отсутствие не означает ноль. Неделя МСК: [понедельник 00:00, следующий
  понедельник 00:00). Уникальные scheduled+completed во всех курсах этого teacher,
  без cancelled/архива; фильтр календаря не сужает явно подписанный счётчик.
- При начале/окончании обучения посреди недели автоматического prorating нет.
  Допустимы явное исключение нормы на конкретную неделю или пауза без недобора.
  Изменение обычной нормы действует со следующей недели; текущая меняется явно.
  Прошлые недельные значения сохраняются, исторический backfill не выдумывается.

D03/D04 и исторический результат T08 сохраняются. D12 остаётся открыт.

## Контракт реализованного backend · 19.10.2026

- `POST /lessons/regular/previews`: клиентский UUID operation_id, action
  create/extend/stop/cancel_future. Create: lesson с публичным student_user_id;
  extend: series_id; weeks1–12/default4. Stop/cancel не принимают weeks/lesson.
- `GET /lessons/regular/operations/{operation_id}`: durable preview либо committed
  receipt. UUID повторяют после timeout; другой payload с тем же UUID →409.
- `POST /lessons/regular/operations/{operation_id}/confirm`: preview_revision и
  явный acknowledge_conflicts. Изменившийся preview →409 с новым preview/revision;
  новый revision нужно просмотреть/подтвердить, старый не пишет встречи.
- `GET /lessons/regular/series/{series_id}`: текущее состояние серии. Receipt —
  исторический результат операции, не заменяет чтение текущей серии.

Модели — lessons/models.py; SQL/locks — repository.py; business/transactions —
RegularLessonsService в service.py; DTO/Depends/thin views в том же модуле.
Модели зарегистрированы db_models, новый409 handler — api/exception_handler.py.
Миграция bc4873ad378e после26ec46040b4c: nullable regular fields старых Lesson;
series/operation tables; unique исходного вхождения и anchor серии, pair CHECK.
Downgrade отказывает при непустой истории; пустые таблицы откатываются без потери
старых уроков. Явный admin purge курса удаляет его серии/receipt через FK cascade,
после purge recovery404; перенос/отмена/архив историю серии не удаляют.

Schedule advisory lock объединяет ordinary create/update/archive, regular batches
и admin restore. Course/recipient locks сохраняют D04/access scope; preview/receipt
записываются в транзакции. Create/extend создают обычные Lesson+LessonStudent;
cancel сохраняет материалы и атомарно создаёт обычные notifications/recalculates D04.
Прошедшие исходные даты не достраиваются задним числом: если ближайшая исходная
неделя продления уже прошла, требуется новая серия с будущей датой (422).

Связанные файлы: course_lifecycle repository/service (restore lock), db_models,
tests/conftest cleanup order, новая migration и tests/migrations/test_t08b.py,
tests/modules/lessons/test_t08b_regular.py; существующие migration tests ожидают новый
head; frontend/src/shared/api/schema.d.ts regenerated, UI не менялся.
Подтверждённый import cycle в avatar_transaction устранён переносом единственного
импорта LifecycleRepository внутрь cleanup; standalone tests_unit44 PASS/1.20s.
