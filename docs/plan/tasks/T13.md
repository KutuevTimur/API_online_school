## Контракт

- `homework_assigned` → ученик; `solution_submitted` → преподаватель;
  `solution_checked` → ученик; `lesson_rescheduled`/`lesson_cancelled` → участники урока.
- Событие в той же транзакции, что действие. Повтор submit/PATCH без перехода
  и правка submitted не создают новых уведомлений. Повторная реальная отмена после
  восстановления scheduled — новое событие. Unique recipient/dedupe_key защищает retry.
- Только ID/type/time/read, без текста ответа, контактов, имён файлов и секретов.
  Target не имеет FK: уведомление сохраняется после purge.
- `GET /notifications?limit=20&offset=0&unread_only=false`, `GET /notifications/unread`,
  `PATCH /notifications/{id}/read` (идемпотентно), `GET /notifications/{id}/target`.
  Все операции только своего recipient, включая admin. Чужой/несуществующий ID → 404.
- Target повторно проверяет object access и submission scope. Недоступный/удалённый
  объект → 200 available=false с русским сообщением и пустыми destination fields.
  Чтение target не отмечает уведомление прочитанным; клиент явно вызывает read.
- `GET /audit-events` только active admin: page/total, actor_user_id/action filters,
  стабильный порядок created_at/source/id. Общий журнал объединяет новые AuditEvent,
  существующие AccountAudit и LifecycleAudit; identity записи — source + id.
  Сохраняет прежние audit records, результаты denied и correlation_id.
- Новые audit события account_create (target user) и teacher_student_link (target связь). Существующие invitation,
  reset, profile/account-status, quota, restore/history/purge остаются источниками.
  Аудит без произвольного payload, паролей/токенов/решений. Объект может быть удалён.
- Клиент T14/T15: polling при открытии и раз в 60 секунд только активной вкладки,
  остановка при logout/hidden, retry с backoff. WebSocket/email/push/бот отсутствуют.
