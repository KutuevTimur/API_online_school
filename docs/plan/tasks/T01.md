# T01 — воспроизводимый local/test и guard

Зависимость T00. Модель Sol default/high при сложной fixture. Не менять предметную область. Требуется отдельная разрешённая тестовая PostgreSQL; при отсутствии runtime подготовить изменения, тесты отметить NOT RUN, не DONE.

Точные точки env loading прочитать до edits. Базовые Config/Depends сохранить.

## Порядок реализации

1. Явно разделить env local/test, без fallback на `.env` для тестов. Все пути тестовых media — временный каталог pytest, не вычисление потенциально реального media root с последующим shutil.rmtree.
2. До любого connection/create/drop/delete в тестовом пути валидировать `MODE=TEST`, имя `lgg_test`, ожидаемый test host/port и явный marker `ALLOW_TEST_DB_RESET=1`. Дополнительно role без прав на dev/prod. Проверка дешёвая и выполняется **до** autouse fixtures и standalone destructive tools. Не разрешать arbitrary `_test` имени при удалённом DSN.
3. Не дублировать Config/engine при import/app/lifespan. Один конфиг на приложение, один engine, dispose при завершении; tests получают свой config/engine через явную dependency override. Не глобальный rewrite DI.
4. Compose dev/test: отдельные проекты/volumes/credentials, test DB только loopback; backend media volume для сохранения файлов после recreation. Redis optional, поскольку прикладного использования не найдено; удалить обязательность env без скрытого подключения Redis.
5. Examples содержат только dummy placeholders. `.dockerignore`: .git/.env*/.venv/media*/caches/test artifacts; разрешить только безопасные examples при необходимости. README — version, prerequisites, exact commands и distinction dev/test; не писать «работает» до запуска.
6. Новый guard тестировать без БД через подменённый connection factory. Проверить, что запрет срабатывает до вызова фабрики и до rmtree. Unit-файл разместить отдельно от опасного autouse conftest либо разделить scope фикстур явным маркером. Это часть T01, а не повод запускать старые fixture для проверки guard.

## Приёмка и команды

- [x] Нет подключения/очистки при MODE≠TEST, неизвестном имени, отсутствии marker, remote/unknown DSN.
- [x] Тестовые файлы удаляются только внутри выделенного tmp path.
- [x] Guard unit tests проходят; минимум 5 отрицательных конфигураций и 1 допустимая.
- [x] `docker compose -f compose.test.yaml config --quiet` проходит, если Docker доступен; вывод interpolated secrets не сохранять.
- [x] Startup/shutdown приложения с synthetic config проверен, engine закрывается.
- [x] `.venv/bin/python -m pytest --collect-only -q` собирается в явно тестовом окружении; это не прохождение всех тестов.
