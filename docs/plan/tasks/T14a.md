## Контракт

1. GET `/courses`: additive `view=all|active|archive` default **all** для совместимости;
   `student_user_id` optional, имеющиеся teacher_user_id/limit/offset сохраняются.
   `my_courses` сейчас фактически не используется: не превращать false в обход scope,
   пометить deprecated в OpenAPI, UI его не передаёт. Точная роль всегда задаёт scope.
2. GET `/lessons`: тот же view default all, существующие date/course/status фильтры;
   добавить `student_user_id` для teacher/admin (student может только свой id либо без).
   Для student `active` исключает архив родителя/урока и историю окончившегося
   участия/teacher link; `archive` — complement внутри видимого scope. Для
   teacher/admin view различает физический архив урока/курса; прекратившееся
   участие помечается read-only отдельно в T14b. Нельзя вычислять archive по
   отсутствию у admin teacher-write прав: это ошибочно скрыло бы все его уроки.
   Отменённый активный урок остаётся active; status отдельный.
3. Course active: не архивирован и у student есть действующее участие/teacher link;
   archive — complement внутри видимого scope. Для teacher/admin физический архив
   курса — основа view, окончившееся участие показывается отдельно через capabilities
   T14b. Не расширять profile scope для поиска бывших учеников.
4. Добавить GET `/homeworks/my/page` **до** dynamic routes; старый `/homeworks/my`
   остаётся array для совместимости. Новый response `PaginationResponseDTO[HomeworkResponseDTO]`.
   `limit=20` 1..100, `offset>=0`, `course_id?`, `status=all|todo|submitted|checked`
   default all, `view=all|active|archive` default all, `overdue_only=false`.
   todo = нет working ответа или draft; исторический checked не подменяет working.
   overdue = deadline не null и < now и status не checked; сдачу не блокирует.
5. Одна строка на Homework, последняя **видимая** placement; сортировка страницы
   по `created_at desc,id desc`; lessons `scheduled_at` + id в том же направлении,
   courses `created_at desc,id desc`. Фильтр/unique/COUNT до LIMIT, не Python после page.
   Deadline и debt semantics T11 неизменны. GET /my array сохраняет прежнюю форму.
6. `total/items` согласованы одним snapshot либо одним SQL с count fallback для
   out-of-range page; filters повторяют predicate count. Неподходящий/чужой фильтр
   даёт пусто/согласованный 403 для запретного student id, а не раскрывает наличие данных.
