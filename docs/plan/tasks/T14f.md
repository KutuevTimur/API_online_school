# T14f — общие файлы, формы и восстановление

Статус **VERIFY локально**; зависит T14e (вход принят владельцем 16.10.2026; технические NOT RUN сохранены).
Явное разрешение владельца: весь локальный T14f, без T15 и без commit/push/PR/merge/deploy/установки skills. Источники A12/A13, DESIGN, T12/D06.
Навыки frontend-design + premium, file-upload/async-resilience/layer-contract.
Файлы: `frontend/src/shared/ui/{UploadQueue,FilePreview,ConfirmDialog,AsyncState}.tsx`,
`shared/api/{files,client,error}.ts`, `app/DraftProvider.tsx`, tests/components/e2e,
при нужде только уточнение безопасных file descriptors T14b, не rewrite T12.

Поведение: один reusable UploadQueue с picker multiple, per-file local preview,
progress/retry/remove/replace,10/100MiB/20MiB и типы D06 до отправки; сервер окончателен.
Original File остаётся в памяти до ack; HEIC local preview может отсутствовать —
показать имя/размер, после сервера WebP. Не использовать avatar512 для фото тетради.
Queue sequential, каждый PATCH ожидает текущую version, остальные ready файлы
сохраняются при failure. Upload100%→«Обрабатываем»→server ack; cancel не означает
rollback сервера. Unknown completion перечитывает состояние, auto retry POST нет.

FilePreview: authorized fetch и Content-Type, image contain/zoom/next/download;
lazy PDF.js6.4.299 и worker той же версии, локальные assets/font/cmaps, без CDN.
Page controls/zoom/selection text layer/accessible labels, pages on demand,
не рендерить 100 страниц сразу, без PDF actions/scripts/annotation authoring.
Blob URL не содержит токен, revoke on close/logout; файл>20MiB из legacy обрабатывать
потоком/Range reader либо fallback download без обещания preview всего архива.
Крупный fullscreen preview закрывается Escape/назад с возвратом фокуса.

Dirty form guard/reauth overlay/per-field422/409 compare подключены как владельцы
A13. No browser confirm кроме реального unload lifecycle. Gallery `/__ui` только DEV:
synthetic PDF/фото, interrupted upload, error/quota/conflict/session examples.
Ошибки локальны к элементу; toast не единственное сообщение.

Приёмка: keyboard и touch без drag;3 фото +4-е→не потеряны; replace/delete без
подмены соседнего файла; PDF page/zoom/download работает в Chromium/WebKit;
повреждённый PDF/401/403/413/quota/timeout/abort дают recovery без утечки URL.
Unit meaningful state machine + E2E real API using existing synthetic Homework;
gallery mocks не заменяют real uploads. npm quality scripts + premium strict audit.

Ручная приёмка: дать dev URL gallery и настоящий защищённый test file; открыть PDF,
увеличить мелкие дроби на фото, пройти клавиатурой, закрыть preview. Сказать фактическое
место media (`lgg-dev_media` при Compose), persistence/restart и способ просмотра,
не просить владельца выбрать storage. Уже принятый D06 повторно не спрашивать;
здесь проверяется UI/устройства, не пересогласование конвертации.
Риски: память вкладки/большой PDF, mobile keyboard/оверлеи, URL cleanup.
Следующее T15a.1. Результаты по факту здесь/STATUS/SESSION_LOG.

## Реализация · 16.10.2026

Использованы существующие frontend-design и frontend-design-premium1.4.0,
DESIGN/A12/A13 и upload/async/layer/permission references; интервью/нового redesign нет.

- `shared/lib/uploadQueue.ts`: последовательная state machine; один append/replace
  с actual expected_version, Original File до ack, byte progress отдельно от processing.
  Стабильные IDs, per-file errors/retry/remove, лимиты10/100/20MiB, HEIC name/size
  fallback. Неопределённый результат/409 блокирует повтор до explicit read; без
  automatic POST/PATCH retry.403/404 блокирует writes; поздние ack/read после logout
  не могут вернуть приватный draft. Другие ready/ошибочные файлы сохраняются.
- `shared/api/files.ts`, `client.ts`, `error.ts`: typed descriptors/answer adapter,
  PATCH/PUT/DELETE и version, защищённый fetch, безопасные path/query, final MIME;
  streaming cap20MiB даже без Content-Length, legacy — explicit download fallback.
  Размер известных исходников хранится в memory; у старых converted descriptors нет
  полного source-size, поэтому итоговые100MiB/quota проверяет сервер, а не догадка UI.
- `UploadQueue.tsx`, `FilePreview.tsx`, `files.module.css`: multiple picker и точная
  replace/delete операция; app confirmation, error остаётся рядом с файлом.
  Фото contain/zoom/next, PDF lazy6.4.299/worker same version, page-on-demand,
  canvas + selectable text layer, page/zoom/download. Actions/scripting/annotations
  не подключаются; нет внешнего viewer/CDN. Blob URLs revoke при close/logout/ack.
- `DirtyFormGuard.tsx`, `ConflictCompare.tsx`, `modalIsolation.ts`, DraftProvider,
  `features/auth/ReauthOverlay.tsx`: native unload guard и app navigation confirmation,
  local/server compare без автоприменения, reauth поверх memory queue; смена user/logout
  очищают состояние. Native inert для root при body portal, ref-count для нескольких
  слоёв; focus trap/return — existing Mantine. Modal header не создаёт второй banner.
- Общие `ConfirmDialog`, theme/styles, AppShell: disabled destructive retry после
  unknown outcome, layer tokens, profile initials aria-hidden; принятая палитра и вид
  сохранены. Runtime axe выявил heading order/background/profile name — исправлено.
- `dev/FilesLab.tsx`, `FileRecoveryExamples.tsx`, router/Gallery: только DEV
  `/__ui/files`, настоящая работа с существующим synthetic Homework/answer;
  отдельные подписанные примеры processing/interrupted/quota/403/409/session/422.
  Authored select и focus422, локальные данные сохраняются. Router query file ID
  позволяет browser Back закрыть preview; query не содержит token/bytes.
- `scripts/t14e_preview.py`: fresh synthetic namespace, отдельный files_student,
  existing Homework + original placement + working answer, реальные PDF/фото через
  существующий upload endpoint. Credentials только в ignored0600 JSON, без печати.
  Backend domain code/schema не менялись. `pdf-assets.mjs` копирует installed exact
  PDF.js assets/LICENSE до dev/build в ignored `public/pdfjs/`; lockfile закреплён.
  Два synthetic fixtures — `frontend/e2e/fixtures/math.pdf`, `notebook.png`.
