## Реализовано

### T12a — storage и защита

`storage/service.py`: async Storage protocol, LocalStorage через PathsConfig,
read-only LegacyStorage, bounded 64 KiB streams, private mode 0600, SHA256,
immutable publication link+fsync без перезаписи. Descriptor-relative openat/
O_NOFOLLOW проверяет все компоненты; absolute/.. /backslash/NUL keys и symlink
escape отклоняются. Cancellation дожидается OS I/O до закрытия descriptor.
S3 SDK не нужен для локального запуска.

FileAsset хранит backend/key/size/проверенный MIME/hash/safe name/state/uploader/
timestamps; явные original_asset_id/download_asset_id FK из Lecture/Homework/
HomeworkSubmissionFile. Pending/failed не скачиваются. Глобального hash lookup нет.
UUID имена на диске не включают пользовательскую подпись; новые PDF имеют одну
копию и один asset. Публичные ID/URL сохраняются, absolute paths скрыты.
Исторические `pdf_file_*` поля временно обозначают и WebP; Content-Type отражает
реальный объект, PDF-вектор не растеризуется. T14 не должен предполагать PDF по
историческому имени поля.

Доменные T06/T07/T11 права проверяются перед open, включая direct file_id/Range.
Один открытый descriptor используется до окончания streaming. Single/suffix/open
Range, 416, private/no-store/nosniff, безопасный Content-Disposition.

20 MiB/file по фактическому stream, ≤10 файлов и ≤100 MiB исходников/ответ.
Count/sum учитывают сохранённые+новые, вычитают заменяемый файл, используют общий
parent/homework lock. Source_size сохраняет исходный размер после нормализации.
Multipart ASGI guard ограничивает до 102 MiB даже без/с ложным Content-Length,
до полного spooling FastAPI. Framework form parser всё равно предшествует
доменной проверке: он не выдаёт данные, но может spool до общего request limit.

PDF проверяется strict pypdf parser, не encrypted/empty. Pillow+pillow_heif
проверяют формат/декодирование/50 MP/один кадр. Один subprocess на Config,
30s timeout, kill+reap, CPU/file-size limits, Linux memory limit. CPU не в event
loop. Office/SVG/HTML/GIF/unknown upload выключены; LibreOffice handlers сохранены.
Это не malware scan: production quarantine/scan — T17.

1 GiB managed materials/answers на ученика, включая материалы его преподавателей
и архивы; уникальные asset IDs считаются один раз. Общий User NO KEY UPDATE lock
сериализует uploads разных курсов; отказ не отрезает старые downloads. Admin может
изменить квоту, действие аудируется. `GET /users/{user_id}/storage` — только свой
пользователь/admin, used/limit/warning (70/85/100%) и course contributions.
`PATCH /admin/users/{user_id}/storage-quota` — admin, strict integer 20 MiB..1 TiB.
Аватары пока не включены в этот документный бюджет. Legacy usage становится точным
после T12c; до миграции count/source sum консервативно резервирует 20 MiB/file.

DB commit публикует metadata+domain FK вместе. При потере COMMIT acknowledgement
компенсация сначала проверяет durable refs; при недоступной БД сохраняет bytes
до reconciliation. Регрессия реально commit→exception подтверждает сохранность.
Ошибка нового upload → rollback и
удаление только новых объектов; failed unlink → durable FileDeletion. Swap/delete
сначала меняет ссылки и очередь в транзакции, потом worker чистит старый объект.
Metadata удаляется после последнего доменного FK, shared refs перепроверяются.

### T12c — legacy transition и recovery

Local-only guard проверяет точные dev/test target и фактические engine/session.
`src.tools.storage_maintenance migrate --actor-user-id ID` — dry-run по умолчанию;
`--apply` копирует без нормализации, independently проверяет hash, сохраняет
file_id/created_at/updated_at, связывает assets в DB commit. Приватный 0600 manifest
пишется до commit и сохраняет old/new поля, keys/hash/size/MIME/course_id.
Old bytes остаются на 7 дней для rollback; при завершении окна вновь проверяется
checksum новых копий. Недоступная/повреждённая новая копия блокирует удаление старой.
Чтение legacy отключается LEGACY_FILE_READS=0 только после нулевого остатка.

Исторические dummy-PDF synthetic smoke не являются валидными PDF. По умолчанию
migration оставляет такой файл неизменным и сообщает failed. Явный local/admin
`--allow-opaque-legacy` сохраняет его bytes/hash как authenticated attachment
application/octet-stream. Это не путь нового upload и не утверждение валидности PDF.
Уploader у импортированного asset — фактический admin-импортёр, не выдуманный автор.

Reconciliation ищет только узнаваемые UUID/.upload имена старше 24h; DB refs,
pending jobs и retained manifests защищают объекты. Повреждённый manifest → fail
closed. Сначала durable queue, потом повторная проверка refs и unlink. Admin purge
снимает retention своих manifest backups; общий путь другого owner сохраняется.
Worker в DEV выполняет цикл раз в 60s и закрывается до engine.dispose; TEST не
запускает background worker. Failed cycle повторяется; лог не содержит путей/ПД.
