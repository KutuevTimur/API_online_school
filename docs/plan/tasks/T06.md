## Endpoint → policy (до реализации)

| Endpoint / действие | Policy |
|---|---|
| users/students | Admin все; teacher только active teacher_students; student 403 |
| users/teachers | Admin все; teacher себя; student active teacher_students |
| users/{user_id}, GET avatar | Self/admin полный профиль; связанный teacher/student минимальная карточка; чужой 404 |
| PATCH profile/avatar, DELETE avatar | Self/admin; teacher не редактирует общего student (D01) |
| PATCH account status | Отдельный admin endpoint; обычная DTO не принимает role/is_active |
| courses list/detail/avatar GET | Admin все; teacher свои; student StudentCourse; фильтр не расширяет scope |
| courses create/update/avatar/archive | Teacher своего курса; hard delete закрыт до безопасного T07 purge |
| lessons list/detail | Admin все; teacher свой Course + Lesson; student персональный LessonStudent |
| lessons create/update/delete | Teacher своего Course + Lesson; admin без учебного workflow |
| course students list | Teacher владелец/admin; nested minimal student, без контактов |
| enroll / add lesson student | Teacher владелец + active teacher_students; для урока также active StudentCourse |
| unenroll/remove lesson student | Teacher владелец; student self-unenroll сохраняется до T07 |
| lectures/homeworks list/file | Admin / teacher владелец Course+Lesson / получатель LessonStudent |
| lectures/homeworks create/delete | Teacher владелец Course+Lesson; tuple IDs проверяется целиком |
| submissions list/detail/file | Та же policy персонального Homework; homework→submission→file сверяется |
| submissions create/student update | Только student получатель |
| submissions teacher update | Только teacher владелец |
| submissions delete | Получатель student / teacher владелец; checked lifecycle — T09/T10 |
| invite/reset/password aliases | Существующий D01/T05b сохраняется |

Чужой объект: 404; запрещённая операция: 403; списки фильтруются до count/pagination.
Отсутствующий профиль никогда не снимает scope. Файлы выдаются только через auth endpoint;
в JSON аватары содержат относительный auth URL, а не локальный путь.

## Реализовано 15.10.2026

- Общие SQL predicates profile/course/lesson/recipient и PermissionRepository +
  ObjectPermissionService; detail/write/file используют ту же границу владения.
  Запросы перенесены из submission service в repository; missing profile fail closed.
- Teacher list/detail/course avatar ограничены владельцем, filter teacher_user_id
  только сужает scope. Admin читает все курсы/занятия/персональные материалы/ответы.
  Total считается до offset (включая пустую страницу занятий).
- Profile lists SQL-scoped по active teacher_students; D01 minimal DTO без email,
  отчества, внутренних profile IDs и контактов; nested enrollment student минимален.
  Полный профиль только self/admin. StudentCourseResponse использует student_user_id.
- Общий профиль/avatar меняют self/admin; teacher не меняет связанного ученика.
  role/is_active отвергаются обычной profile DTO, status вынесен в admin endpoint,
  с auth_version/revoke refresh и audit. Admin profile/avatar mutations также audit.
- Auth GET avatar user/course; публичный avatar_path — относительный URL.
  Parent IDs и direct file_id сверяются; foreign/missing → 404, запрет операции → 403.
- Enroll требует active teacher_students; add lesson student также active
  StudentCourse. Teacher hard delete закрыт; admin purge — отдельный T07 workflow.
