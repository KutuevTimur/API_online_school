## T15c.1 — пользователи, приглашения и связи

Admin `/admin/users`: q in memory, role/active/activated/page in URL. Detail
доступен direct link; создать teacher/student, edit profile, issue invite/reset
по состоянию; показать expiry и copy link. Никогда не задавать пароль за ученика.
Подключить существующего student ко второму teacher: два searchable selectors
с именем+username, review пары, POST teacher_students; существующий link идемпотентен.
Завершить связь — отдельное подтверждение с пояснением сохранения истории и
независимости другого teacher. Блокировать общий аккаунт — другое действие,
чётко указать отключение всех teacher sessions; не смешивать с local detach.
Storage quota report/change bounded MB/GB UI→bytes (уточнение22.10), used/limit текстом и warning,
не выдумывать освобождение места при изменении квоты.

Приёмка: состояния считываются из admin DTO, запросы не получаются из глобального
teacher каталога, поля роли не изменяются через profile PATCH. Void/null invite
не показывает stale ссылку прежней попытки; clipboard failure recovery. Backend
audit присутствует для чувствительных действий. Real API E2E shared student2 teachers,
reset/inactive/activation и permission403, npm checks, keyboard/mobile/audit.
Риск: отключить общий аккаунт вместо одной связи. Ручная приёмка: создать teacher,
подключить existing synthetic student, выпустить reset, завершить только одну связь.

## T15c.2 — все курсы, архив, purge и журнал

Зависимость .1. Course list filters teacher/student/view,page; detail read-only
учебной части с явным recipient. Restore курса не restore отдельных уроков;
restore урока отдельный. History access revoke/return с отдельным подтверждением
и именем ученика, не автоматический эффект archive. Purge из отделённой зоны,
Dialog с typed exact course name и course_id; cancel default focus. POST purge
response cleanup completed/failed: курс удалён после commit, если cleanup failed
показать pending cleanup, не повторять purge. Admin retry cleanup отдельная кнопка.
Audit list actor/action/time/result, pagination и два существующих filters actor/action;
не обещать date filters без API. Источник+id — стабильный key объединённого audit.
Нет admin учебной проверки/создания уроков от имени teacher.

Приёмка: archive read/download; restore не открывает gaps/отдельные архивы;
purge только admin typed match,409/400 сохраняют Dialog/ввод, network unknown
refetch; audit не содержит token/ответов. Реальный synthetic курс только для
purge tests, не demo история владельца. E2E и negative role checks, npm checks,
premium audit. Ручная приёмка: restore synthetic archive и отмена purge Dialog,
затем purge **специально созданного disposable synthetic курса** по owner action;
никогда не удалять реальные курсы для демонстрации. Действие пользователя не
отмечать выполненным заранее. Следующее T16.1.
